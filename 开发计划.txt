一、项目概述
------------------------------------------------------------
小雨超级文件批量改名专家是一款小巧、实用的文件批量
改名工具。本软件针对日常文件整理中大量文件逐个改名
费时、费力的问题而设计，可以让普通用户在几分钟内完
成几百个文件的统一改名工作。

开发平台：  C 语言 + Win32 SDK（纯 API，不用 MFC）
编译环境：  Visual C++ 6.0（同时验证 MinGW 可编译）
目标系统：  Windows 2000 / Windows XP / Windows 2003
界面风格：  Windows Classic 传统风格（标准系统控件、
            灰色界面、菜单栏、工具栏、状态栏）
程序体积：  实际约 300KB，绿色单文件，
            不写注册表，不装运行库，拷贝即用

二、功能设计
------------------------------------------------------------
1. 文件添加（第一章）
   - "添加文件"对话框，支持多选
   - "添加目录"对话框，一次导入整个文件夹
   - 支持拖拽文件 / 文件夹到列表（OLE 拖放）
   - 文件列表用 ListView 控件（报表视图），显示：
     原文件名、新文件名、扩展名、大小、修改日期
   - 列表支持排序、右键菜单（移除、清空、全选）

2. 改名规则（第二章，核心）
   - 统一编号：文件名 + 起始号码 + 位数补零
     （如：照片_001.jpg、照片_002.jpg）
   - 添加前后缀：在文件名前 / 后插入指定文字
   - 查找替换：支持区分大小写选项
   - 修改扩展名：统一改为指定扩展名（带确认提示，
     防止用户误改系统文件类型）
   - 全部替换：整个新文件名用统一名称 + 编号
   - 大小写转换：全部大写 / 全部小写
   - 以上规则可自由组合，由用户在"改名方式"分组框
     中选择，右侧参数区随选择切换

3. 预览与执行（第三章）
   - 所有操作先在列表中预览"新文件名"一栏，未应用
     前不改动磁盘上任何文件（安全第一）
   - 状态栏实时显示：文件总数、符合条件数
   - "开始改名"按钮，带进度对话框（进度条 + 当前文件名）
   - 改名失败（重名、只读、占用）时给出具体原因和
     解决办法，可跳过继续
   - 改名完成后弹出统计：成功 X 个，失败 X 个

4. 辅助功能（第四章）
   - 撤销上次改名：改名将原文件名记录到程序目录下
     undo.dat，可一键恢复
   - 参数记忆：窗口位置、上次使用的规则保存到
     rename.ini，下次启动自动恢复
   - 帮助菜单：调用 CHM 帮助文件（暂时内置 About
     页面的简要说明，CHM 视时间补充）

三、界面设计（Windows Classic 风格）
------------------------------------------------------------
主窗口布局（800x540，可缩放）：
 +------------------------------------------------------+
 | 文件(F)  编辑(E)  规则(R)  帮助(H)          <- 菜单栏
 |------------------------------------------------------|
 | [添加文件][添加目录][移除][清空][开始改名]    <- 工具栏
 |------------------------------------------------------|
 | +-- 改名方式 --+  +-- 参数设置 ---------------+ |
 | | (o)统一编号  |  |  起始号码 [ 1 ] 位数 [ 3 ] | |
 | | (o)添加前后缀|  |  前缀 [____] 后缀 [____]   | |
 | | (o)查找替换  |  |  ...                        | |
 | +--------------+  +-----------------------------+ |
 | +-- 文件列表（ListView 报表视图）-----------------+ |
 | | 原文件名 | 新文件名 | 扩展名 | 大小 | 修改日期 | |
 | |          |         |        |      |          | |
 | +--------------------------------------------------+ |
 |------------------------------------------------------|
 | 就绪 | 文件数：0 | 小雨超级文件批量改名专家 V1.0    | <- 状态栏

配色：一律使用系统标准色（COLOR_BTNFACE 灰、
COLOR_WINDOW 白），不用自绘，保证在经典主题下与
Windows 自带程序完全一致。

四、技术方案
------------------------------------------------------------
- 语言：C，纯 Win32 API，避免依赖 MFC / CRT 大库
- 通用控件：ListView、TreeView（目录树，视进度决定）、
  进度条、工具栏、状态栏，InitCommonControlsEx 初始化
- 拖放：DragAcceptFiles + WM_DROPFILES（简单可靠，
  OLE 拖放作为第二版本改进）
- 文件操作：MoveFile（同盘改名）+ SHFileOperation 备用
- 字符串：全部使用 TCHAR，同时定义 UNICODE / _UNICODE，
  保证在 XP 上支持中文文件名
- 内存：列表数据自建双向链表管理，注意释放，杜绝泄漏
- 撤销记录：undo.dat 用文本格式（一行一个：新名|旧名），
  出错容易手工修复
- 配置文件：GetPrivateProfileString 读写 rename.ini

六、实际完成情况（与原计划不同的地方）
------------------------------------------------------------
1. 图标：原打算直接用系统 DLL 里的图标，结果现在的系统
   里那些图标都被换成扁平样式了，只好从网上找了一套
   Windows XP 原版 shell32 图标（16/32/48 三种尺寸齐全），
   挑出程序图标、工具栏、目录树和帮助窗口要用的十几个。
2. 界面：程序故意不声明高 DPI 感知，一律按 96dpi 布局，
   由系统整体拉伸，这样在 150% 等高缩放屏幕上就是那种
   经典（略微发糊）的观感；界面字体固定为宋体 9pt 且不
   做平滑，直接走字体自带的点阵。
3. 帮助：没有编译 CHM 文件（现在系统上也没有 HTML Help
   Workshop 了），改成程序内自带一个仿 CHM 阅读器的帮助
   窗口：工具栏（后退/前进/主页/打印/隐藏目录）+ 左侧
   "目录/索引"标签页 + 右侧 RichEdit 显示 RTF 正文，帮助
   正文直接编在 EXE 里，绿色单文件。
4. 体积：实际约 300KB（静态链接，不依赖任何运行库）。
5. 测试环境：手上只有较新的系统，XP SP2/SP3 未能实机
   测试，仅保证不调用高版本系统专有的 API（用到的新
   API 一律动态加载）。

七、注意事项（写给自己的备忘）
------------------------------------------------------------
1. 改名前必须预览，绝不让用户"盲改"——这是本软件的
   立身之本，宁可慢一点也要稳。
2. 非法字符、重名冲突一定要在预览阶段就标红提示，
   不要等到 MoveFile 失败才报错。
3. 对系统文件夹（如 C:\Windows）操作时给出警告。
4. 代码写得菜不要紧，但注释要写清楚，方便自己以后
   维护升级 V1.1。
5. 每晚写完记得备份源码一份到另一个目录，血泪教训。

八、V1.1 版本开发记录（2007 年）
------------------------------------------------------------
V1.1 的主题是“把能改名变成更省事”，共四项功能：

1. 导入时包含子文件夹
   - “添加目录”支持递归导入子文件夹，递归深度有上限，
     不跟随符号链接；
   - 首次遇到含子文件夹的目录会询问一次，选择记入
     rename.ini 的 Options\SubDir，下次沿用；
   - “文件”菜单增加“添加目录时包含子文件夹”开关。
   实现：main.c 的 AddDirectoryItemsEx()、HasSubDir()、
   AskSubDirOnce()。

2. 按拍摄日期编号
   - 新增 exif.c / exif.h，只解析 JPEG 的 APP1/EXIF 段，
     优先取 DateTimeOriginal（0x9003），依次回退到
     DateTimeDigitized（0x9004）、DateTime（0x0132）；
   - 没有 EXIF 的文件自动改用文件修改时间，不报错；
   - 日期格式支持 yyyy yy mm dd hh nn ss，其余字符原样保留；
   - 列表最后一列在按日期编号时显示拍摄日期。
   实现：exif.c 纯 C，不依赖任何第三方库。

3. 查找替换支持正则表达式
   - 新增 regex.c / regex.h，回溯法实现，支持
     . * + ? [] () \1..\9 ^ $ \d \w \s 及转义；
   - 表达式在预览时编译一次，供全部文件共用；
   - 表达式非法时状态栏给出中文原因，预览全部标红。
   实现：regex.c 纯 C。

4. 改名方案（预设）保存
   - rename.ini 增加 [Preset1] ～ [Preset9] 节，字段与
     Options 节同名；
   - 参数区增加“方案”下拉框与“保存方案...”、“删除”按钮；
   - 保存方案时弹出简单的中文输入框给方案起名。
   实现：main.c 的 WriteOptionsToSection()、
   ReadOptionsFromSection()、RefreshPresetCombo()、
   LoadPreset()、DoSavePreset()、DoDeletePreset()、
   PromptText()。

其它：
   - 关于框、帮助文档、README、版本资源全部同步更新为
     V1.1；
   - 版本资源 FILEVERSION / FileVersion / ProductVersion
     改为 1,1,0,0 / 1.1.0.0 / V1.1 正式版；
   - 自测：regex.c 与 exif.c 各写了无界面测试程序，
     全部通过（测试程序不属于发布内容）；
   - 编译仍然 -Wall 无警告，EXE 体积与 V1.0 相当。

十、V1.4.1 版本开发记录（2007 年）
------------------------------------------------------------
V1.4.1 是界面打磨版本，功能与 V1.1 完全一致，只重做
了主界面的布局，具体做法以代码为准：

1. 窗口与布局
   - 初始客户区加大到 840×620（一律用 S() 包裹），
     DoLayout() 中 pad 提至 8、blockH 提至 160；
   - 最小窗口尺寸提到 800×600，小分辨率下完整可用；
   - “改名方式”分组框加宽到 140，单选框行距 20。

2. 工具栏
   - 按钮改为纯 16×16 图标小按钮（保持经典凸起样式），
     原来的文字全部移到鼠标提示里；
   - 增加 TBSTYLE_TOOLTIPS，在主窗口 WM_NOTIFY 里处理
     TTN_GETDISPINFOW，按按钮 ID 返回“名称＋快捷键”。

3. 参数设置区
   - 标签列宽统一为 70，行距统一为 28，消灭 66/70/74
     混用导致的对不齐；
   - “保存方案/删除”按钮按分组框右边缘反推定位，分组
     框变宽时按钮跟着走；
   - “修改扩展名”的警告文字改为单行并以“※”开头；
   - “按日期编号”的提示文字宽度按剩余空间计算。

4. 文件列表与状态栏
   - 列表增加 LVS_EX_FULLROWSELECT（整行选中），列宽
     随新窗口调整；
   - 状态栏三栏按窗口宽度比例计算，缩小窗口不重叠。

其它：
   - 版本资源改为 1,4,1,0 / 1.4.1.0 / V1.4.1 正式版；
   - 关于框、帮助文档（程序内嵌与《帮助文档.txt》）、
     README 全部同步更新，工具栏专题按新界面改写；
   - 编译仍然 -Wall 无警告，EXE 体积约 320KB。
